# Customer Setup Guide

## For Android Tablet Users

---

## **Installation (One-Time)**

### **What You'll Receive:**
- One APK file (e.g., `SocialMediaCounter.apk`)
- Setup instructions

### **Installation Steps:**

1. **Connect to PC or Download File**
   - Receive APK file via email, USB drive, or download link

2. **Transfer to Tablet**
   - Option A: Via USB cable to PC, copy to tablet storage
   - Option B: Email APK and download directly on tablet
   - Option C: Use File Manager to access network share

3. **Install App**
   - Open File Manager on tablet
   - Locate the APK file
   - Tap the APK file
   - Tap "Install"
   - Wait for installation to complete

4. **Allow Permissions**
   - Grant requested permissions when prompted
   - Tap "Open" or find app in home screen

---

## **First Start**

After installation, the app will:
- ✅ Automatically appear on home screen
- ✅ Start running services
- ✅ Be ready to use immediately

## **Daily Use**

1. **Power On Tablet**
   - App starts automatically
   - No manual action needed

2. **Open App**
   - Tap app icon on home screen
   - Or keep running in background

3. **Monitor Social Media Counters**
   - View live counts
   - See displays updating in real-time

## **Changing Configuration**

If you need to change settings (API keys, URLs, etc.):

### **Option 1: Request Updated APK (Easiest)**
- Contact support with required changes
- Receive new APK file
- Reinstall following steps above

### **Option 2: Edit on Device (Advanced)**
- Requires technical knowledge
- Connect tablet to PC via USB
- Use developer tools to modify configuration files

---

## **Troubleshooting**

### **"App won't install"**
- Ensure USB debugging is enabled (Settings → Developer Options)
- Try again or contact support

### **"App crashes on startup"**
- Restart tablet
- Try uninstalling and reinstalling
- Contact support if issue persists

### **"Counters not updating"**
- Check internet connection
- Verify API keys are correct (contact support)
- Restart the app or tablet

### **"Can't find app after install"**
- Swipe up from home screen to see all apps
- Tap app name to launch
- Or use search function to find it

---
