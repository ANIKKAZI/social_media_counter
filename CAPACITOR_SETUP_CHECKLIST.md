## **Building Your First APK**

### **Quick Build**
```bash
npm run deploy:android
```

This runs:
1. `npm run build` - Create production build
2. `npx cap sync android` - Sync with Android
3. `npx cap open android` - Open Android Studio

### **In Android Studio**
1. Wait for Gradle to sync
2. Click **Build → Generate Signed APK**
3. Follow wizard to create signing key
4. APK will be at: `android/app/build/outputs/apk/release/app-release.apk`

## **Deployment Workflow**

### **For Each Customer**

```
1. Update .env with customer-specific values
   ├── META_ACCESS_TOKEN
   ├── GOOGLE_PLACES_API_KEY
   └── etc.

2. Build APK
   └── npm run deploy:android

3. Generate Release APK in Android Studio
   └── Build → Generate Signed APK

4. Install on tablet
   └── adb install app-release.apk

5. Test on device
   └── Verify all features work

6. Customer receives tablet
   └── App auto-starts on boot
   └── Ready to use immediately
```

## **Important Notes**

### **APK Signing**
- Create signing key ONCE during first build
- Reuse SAME key for all future builds
- Keep key safe - you'll need it for app updates
- Don't share key with others

### **Configuration Changes**
- Edit `.env` file
- Run `npm run build:android`
- Generate new APK
- Install on tablet

### **Updates to Customers**
- Generate new APK with updated values
- Send APK to customer
- Customer uninstalls old app
- Customer installs new APK

## **Troubleshooting**

### **"Android SDK not found"**
```bash
# Set environment variable or reinstall Android Studio
# https://developer.android.com/studio/install
```

### **"Gradle build fails"**
```bash
# In Android Studio:
# File → Project Structure → SDK Location
# Verify paths are correct
```

### **"Can't connect to device"**
```bash
# Enable USB debugging on tablet
# Settings → Developer Options → USB Debugging
adb kill-server
adb start-server
adb devices
```

### **"APK won't install"**
```bash
# Clear previous version first
adb uninstall com.socialmediacounter.app
adb install app-release.apk
```
